<div class="textcontainer"> <p class="margin"></p> <h2 class="main-header">Final Project: Customizable LED Picture Frame</h2> <h4 class="section-header">Overview</h4> <div class="section-container"> <p>I want my final project to be a form of room augmentation: a large, poster-sized LED "picture frame" that can display animations, drawings, and patterns. The core idea is open-ended customization: instead of one fixed function, the frame can be transformed by uploading different scripts/animations.</p> <p>The physical format is a standard <b>24 x 36 inch</b> frame filled with an LED grid. A diffuser layer spreads light evenly, and a divider grid (laser-cut or 3D printed) separates pixels/sections for cleaner visuals.</p> <p>Instead of an Arduino, I plan to use an <b>ESP32</b> so I can have stronger control and enable wireless updates (Wi-Fi/Bluetooth), making it easier to upload animations without relying on USB every time.</p> </div> <h4 class="section-header">Design Considerations</h4> <div class="section-container"> <ul> <li><b>Controller placement:</b> deciding whether the microcontroller lives outside the frame or inside the frame in its own enclosure (heat protection and safety).</li> <li><b>Weight + mounting:</b> keeping materials light enough that the whole system can hang on a wall reliably.</li> <li><b>LED wiring strategy:</b> connecting multiple LED strips so they can be powered and controlled effectively from the ESP32 (including power injection and clean data routing).</li> </ul> </div> <h4 class="section-header">Current 3D Model</h4> <div <div class="section-container"> <p><b>Electronics</b></p> <ul> <li>ESP32 development board</li> <li>USB cable for programming</li> <li>330 ohm resistor (data line protection)</li> <li>1000 uF capacitor (power stabilization)</li> </ul> <p><b>LED System</b></p> <ul> <li>2x rolls WS2812B LED strip (5 m, 60 LED/m)</li> <li>3-pin JST LED connectors</li> <li>22 AWG wire (for LED power and data lines)</li> </ul> <p><b>Power</b></p> <ul> <li>5 V 20 A LED power supply</li> <li>AC power cable</li> <li>DC screw terminal / barrel connector</li> </ul> <p><b>Diffuser</b></p> <ul> <li>1x frosted acrylic sheet (24 x 36 in, ~3 mm thick)</li> </ul> <p><b>Divider Grid (3D Printed)</b></p> <ul> <li>1 spool black PLA filament</li> <li>3D printed pixel divider modules (tile pieces forming the grid)</li> </ul> <p><b>Frame / Structure</b></p> <ul> <li>Wooden frame pieces (for 24 x 36 poster frame)</li> <li>1/2-inch plywood backing board (24 x 36)</li> <li>Wood screws</li> <li>Wood glue</li> </ul> <p><b>Mounting</b></p> <ul> <li>French cleat wall mount</li> <li>Small standoffs for mounting electronics</li> </ul> <p><b>General Hardware</b></p> <ul> <li>M3 screws or small machine screws</li> <li>Heat shrink tubing</li> <li>Zip ties or cable clips for wire management</li> </ul> <p>This list is a draft and will be finalized after MVP prototyping and TA feedback.</p> </div> <h4

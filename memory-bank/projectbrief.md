# Project brief: PS70 course site

## Scope

Static documentation site for **PS70 Spring 2026** (Intro to Digital Fabrication). Each week lives in its own folder with `index.html`, Bootstrap, shared `style.css`, and Strapdown for markdown-like content inside `<xmp>`.

## Core requirements

- Week pages match a consistent structure: nav (Spring 2026), `h2.main-header`, `h4.section-header`, `div.section-container`, image grids, captions, optional video.
- Home `index.html` uses `week_N_image.*` as the tile thumbnail for each week where applicable.
- First person voice for student project writeups unless noted otherwise.
- Prefer web friendly assets: MP4 in `video/` subfolders, resized JPEGs in `web/` when originals are huge or HEIC.

## Recently completed work

- **Week 7 (Outputs):** Full MVP page for LED picture frame:7×8 WS2812 grid, ESP32, companion app narrative, firmware timing section, embedded muted MP4s under `07_outputs/video/`.
- **Week 8 (CNC):** Hidden Leaf headband ShopBot project on MDF, Illustrator trace workflow, honest mold post processing status, images under `08_cnc/web/` for page load.

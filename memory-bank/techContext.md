# Tech context

- Static HTML, Bootstrap 5, custom CSS, Strapdown.js.
- Hosted via git (GitHub Pages or similar when pushed to `main`).

- macOS `sips` for HEIC to JPEG and downscaling for `08_cnc/web/`.

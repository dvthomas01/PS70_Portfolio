# Product context

## Purpose

The site documents weekly assignments and the final project for PS70: fabrication, electronics, CNC, networking, and integration narratives with photos and video.

## Audience

Course staff, peers, and the student’s public portfolio readers.

## Experience goals

- Easy navigation from home grid to each week.
- Readable, image led writeups that show process, failures, and recovery.
- Honest status for incomplete steps (e.g. Week 8 mold not yet poured).

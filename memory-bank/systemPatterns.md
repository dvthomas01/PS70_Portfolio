# System patterns

## Page template

- `index.html` per week: Bootstrap5 CSS from CDN, `../style.css`, navbar with Home, About, Final Project.
- Body: `<xmp style="display:none;">` wrapping HTML fragments Strapdown renders.
- Common classes: `textcontainer`, `section-header`, `section-container`, `image-grid-2`, `image-grid-3`, `center-column`, `project-img`, `caption`.

## Media conventions

- **Video:** `<video class="project-img" controls muted playsinline preload="metadata">` with MP4 source.
- **Week 7 videos:** `07_outputs/video/*.mp4` (muted H.264 exports).
- **Week 8 photos:** `08_cnc/web/*.jpg` optimized max width ~1400px; PNGs for diagrams at repo root of `08_cnc/`.

## Writing

- First person for project descriptions.
- User preference (Week 8): avoid hyphens and em dashes in body copy where possible, use commas and periods.
